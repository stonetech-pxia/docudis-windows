# Contributing

Issues are welcome: bug reports, missed or wrong detections, and feature
requests. Never put real personal data in an issue. Use made-up names and
numbers instead.

This repository does not accept code contributions (pull requests) for now.

Detection rules and the anonymization engine live in
[docudis-core](https://github.com/stonetech-pxia/docudis-core), which accepts
pull requests under Apache-2.0.
